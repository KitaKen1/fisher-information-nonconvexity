# Standalone Lean4Web proof

[Fisher41Lean4Web.lean](Fisher41Lean4Web.lean) contains the complete proof in one file and
imports only Mathlib. It includes the 293 kernel-checked numerical cells and the parts of
[Tau Ceti](https://github.com/TauCetiProject/TauCeti) that the proof uses (Apache 2.0, with their
copyright notices kept). Use Lean **v4.35.0-rc3**.

```bash
lake exe cache get
lake build
```

The file ends with `#print axioms` for `Fisher41.paperTheorem1` and
`Arxiv.«2605.18081».fisherInformationConvexity`.

It was tested locally with Mathlib `1b5006ca00888f8aaafa8939b28787d423e44bba`. The
`v4.35.0-rc3` project of Lean4Web may use a nearby Mathlib revision; for example, it used
`5e0c4e52` in October 2026, 79 commits earlier. A name-level comparison of the declarations
added or removed between these two revisions found none that the file uses. The file has not
yet been run on Lean4Web itself.

Checking the whole file took about 6 minutes on the test machine, which was heavily loaded. Most of that time goes to the numerical cells, which the kernel evaluates.

The file is generated by `../lean/scripts/make_lean4web.py`.
